# Minhas Notas de Cibersegurança
Este repositório reúne minhas anotações iniciais sobre redes de computadores, segurança da informação e cibersegurança.

## Objetivo
Registrar minha evolução nos estudos, organizar conceitos importantes e construir uma base técnica para atuar na área de tecnologia e segurança.

## Temas estudados
- Fundamentos de Hardware e Software
- Fundamentos de redes
- Endereçamento IP
- DNS
- DHCP
- Gateway
- Firewall
- VPN
- Segurança da informação
- Phishing e engenharia social

## Método de organização
Cada conceito será registrado com uma estrutura simples, utilizando minha adaptação do método Feynman. O objetivo é que a explicação seja simples, visual e que faça sentido com situações reais:
1. O que é: Explicação direta do conceito.
2. Para que serve: Função principal do conceito.
3. Imagem mental ou analogia: Uma comparação simples para facilitar a compreensão e a memorização.
4. Onde aparece na prática: Situações reais em que esse conceito pode ser observado.
5. Exemplo simples: Um exemplo cotidiano ou técnico.
6. Relação com segurança: Como esse conceito se conecta com riscos, proteção, ataques, defesa ou boas práticas de segurança.
7. Resumo em uma frase: Uma frase curta para fixar a ideia principal.

Estou construindo minha base técnica de forma gradual, buscando compreender os conceitos, relacioná-los com situações reais e registrar minha evolução ao longo dos estudos.

## Como estudo

Utilizo uma adaptação do método Feynman para verificar se realmente compreendi os assuntos estudados.

Sempre que possível, procuro responder:

1. O que é?
2. Para que serve?
3. Como funciona?
4. Qual seria uma analogia simples?
5. Onde aparece na prática?
6. Como se relaciona com segurança?
7. Consigo explicar com minhas próprias palavras?

O objetivo é transformar conceitos técnicos em explicações claras e compreensíveis.
